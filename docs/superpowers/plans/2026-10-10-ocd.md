# ocd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ocd` helper daemon that mints OpenCode pair links via TUI, web button, and Telegram.

**Architecture:** One Go binary, SQLite store, single mint function shared by all fronts. Polling first, webhook phase 2.

**Tech Stack:** Go 1.27, modernc.org/sqlite (pure Go), spf13/cobra, charmbracelet/bubbletea+lipgloss+huh, go-telegram/bot

**Spec:** `docs/superpowers/specs/2026-10-10-ocd-design.md`

## Global Constraints

- Go 1.27 required (`go 1.27` in go.mod).
- Pure-Go SQLite only (modernc.org/sqlite), no cgo.
- `ocd` with no args opens TUI, `ocd serve` runs daemon (mirrors opencode).
- Single owner Telegram ID in config, silent drop for others.
- Rate cap enforced before any `opencode pair` exec.

## Review Focus

- Expired cookie shown as usable (expects countdown never negative, shows EXPIRED + nudge).
- Concurrent mints for same device double-exec (expects one exec, second waits or denied by cap).
- Telegram non-owner gets reply (expects silent drop, no info leak).
- `/pair` without Access JWT mints anyway (expects 401, no mint row).
- Webhook junk body causes work (expects instant 403 on bad secret, no DB write).

package store

import (
	"database/sql"

	_ "modernc.org/sqlite"
)

type Device struct {
	Name      string
	Platform  string
	ExpiresAt int64
}

type Store struct{ db *sql.DB }

func Open(path string) (*Store, error) {
	db, err := sql.Open("sqlite", path)
	if err != nil {
		return nil, err
	}
	s := &Store{db: db}
	if err := s.migrate(); err != nil {
		db.Close()
		return nil, err
	}
	return s, nil
}

func (s *Store) Close() error { return s.db.Close() }

func (s *Store) migrate() error {
	_, err := s.db.Exec(`CREATE TABLE IF NOT EXISTS devices(name TEXT PRIMARY KEY, platform TEXT, last_cookie_at INTEGER, expires_at INTEGER);
CREATE TABLE IF NOT EXISTS mints(id INTEGER PRIMARY KEY AUTOINCREMENT, device TEXT, via TEXT, at INTEGER);`)
	return err
}

func (s *Store) AddDevice(name, platform string) error {
	_, err := s.db.Exec(`INSERT INTO devices(name, platform, last_cookie_at, expires_at) VALUES(?,?,0,0)
	ON CONFLICT(name) DO UPDATE SET platform=excluded.platform`, name, platform)
	return err
}

func (s *Store) GetDevice(name string) (Device, bool) {
	var d Device
	err := s.db.QueryRow(`SELECT name, platform, expires_at FROM devices WHERE name=?`, name).Scan(&d.Name, &d.Platform, &d.ExpiresAt)
	return d, err == nil
}

func (s *Store) TouchMint(device, via string) error {
	_, err := s.db.Exec(`INSERT INTO mints(device, via, at) VALUES(?,?,strftime('%s','now'))`, device, via)
	return err
}
```

package mint

import (
	"errors"
	"time"

	"github.com/mfenderov/ocd/internal/store"
)

var ErrRateLimited = errors.New("rate limited")

func Mint(st *store.Store, exec func() (string, error), device, via string) (string, error) {
	if st.CountRecentMints(device, time.Hour) >= 5 {
		return "", ErrRateLimited
	}
	if st.CountRecentMints("", 24*time.Hour) >= 20 {
		return "", ErrRateLimited
	}
	link, err := exec()
	if err != nil {
		return "", err
	}
	_ = st.TouchMint(device, via)
	_ = st.RefreshExpiry(device, 30*24*time.Hour)
	return link, nil
}
```
