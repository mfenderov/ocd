# Fleet Box Plan (Plan 1 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each `ocd serve` box an authenticated admin listener, a heartbeat sender, and rotation-epoch tracking, so the Worker API (Plan 2) has something to call.

**Architecture:** Extend the existing Go daemon in place. New `/admin/*` routes on the same `127.0.0.1:49400` mux behind Bearer-token auth; a heartbeat goroutine POSTs to the Worker every 30s; a password-epoch counter in SQLite proves rotation. No new binaries, no new ports.

**Tech Stack:** Go 1.27, modernc.org/sqlite (pure Go, already vendored), net/http stdlib only.

**Spec:** `docs/superpowers/specs/2026-10-11-fleet-console-design.md`

## Global Constraints

- Go 1.27 required (`go 1.27` in go.mod).
- Pure-Go SQLite only (modernc.org/sqlite), no cgo.
- Never build shell strings from request input: `exec.Command` with fixed argv only, no `sh -c`.
- Secrets from env only (`OCD_ADMIN_TOKEN`, `OCD_HEARTBEAT_TOKEN`, `OCD_ENROLL_TOKEN`), never logged, never in repo.
- Heartbeat interval 30s, stale threshold 90s (spec defaults).
- Single SQLite writer assumption holds: keep `db.SetMaxOpenConns(1)` as-is.

## Review Focus

- Heartbeat replayed by an attacker keeps a dead box "online": reject old seq/timestamps (Task 7 test pins it).
- Two boxes share one `BOX_ID` (cloned env): Worker binds token→id, but box must send stable id from `OCD_BOX_ID`, never self-chosen per boot (Task 7 test pins env requirement).
- Retry after Worker timeout mints twice: idempotency key reuses the unclaimed token (Task 4 test pins single exec).
- Crafted request params reach a shell: no endpoint takes shell input; revoke/mint use fixed argv (Task 5 test asserts exec argv).
- Revoke while box offline then wake: epoch proves rotation; tombstone clearing is Worker's job, box only reports epoch honestly (Task 1 test pins monotonic bump).
